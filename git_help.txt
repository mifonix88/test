Основные команды Git для различных ситуаций:

начало работы с репозиторием (см. также: git help tutorial)
	clone Клонировать репозиторий в новый каталог
	init Создать пустой репозиторий Git или повторно инициализировать существующий

работа с текущими изменениями (см. также: git help everyday)
	add Добавить содержимое файла в индекс
	mv Переместить или переименовать файл, каталог или символьную ссылку
	restore Восстановить файлы рабочего дерева
	rm Удалить файлы из рабочего дерева и из индекса

просмотр истории и состояния (см. также: git help revisions)
	bisect Использовать двоичный поиск для нахождения коммита, добавившего ошибку
	diff Показать изменения между коммитами, коммитом и рабочим деревом и т.д.
	grep Вывести строки, соответствующие шаблону
	log Показать журнал коммитов
	show Показать различные типы объектов
	status Показать состояние рабочего дерева

управление и изменение общей истории
	backfill Загрузить отсутствующие объекты в частичном клоне
	branch Показать, создать или удалить ветки
	commit Записать изменения в репозиторий
	merge Объединить две или более историй разработки
	rebase Перезаписать коммиты поверх другого базового коммита
	reset Сбросить текущий HEAD до указанного состояния
	switch Переключить ветки
	tag Создать, показать, удалить или проверить теги

совместная работа (см. также: git help workflows)
	fetch Загрузить объекты и ссылки из другого репозитория
	pull Загрузить из другого репозитория и интегрировать с ним или с локальной веткой
	push Обновить удалённые ссылки вместе со связанными объектами

'git help -a' и 'git help -g' выводят список доступных подкоманд и концептуальных руководств.
Для получения справки по конкретной подкоманде или концепции используйте 'git help <команда>' или 'git help <концепция>'.
Общий обзор системы см. в 'git help git'.




git remote add origin https://github.com/mifonix88/test.git #подключить репозиторий
git pull #скачать изменения
git add . #в индекс 
git commit -m "Коменнт" #Записать изменения в репозиторий (локально)
git push -u origin main #Записать на сервер

git restore del.txt # Восстановить файл из последнего коммита (локально)
git checkout e7f0f1e -- del.txt 

git branch -vv# Посмотреть ветки
git branch testing #Новая ветка
git log --oneline --decorate #колмиты
git switch testing #Переключение между ветками (можно вместо switch использовать checkout)
git merge hotfix #слияние ветки (вызывается из master)
git branch -d hotfix #Удаление ветки (например после слияния)
